# Smart Energy Monitoring System using ESP32

## Project Overview
An IoT-based system designed to monitor voltage, current and power consumption.

## Hardware Components
- ESP32
- ZMPT101B Voltage Sensor
- ACS712 Current Sensor
- LCD Display

## Software Requirements
- Arduino IDE
- Blynk IoT

## Working
The sensors measure voltage and current. ESP32 processes the readings and displays the monitoring data through the LCD and Blynk dashboard.
